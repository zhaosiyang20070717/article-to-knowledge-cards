# make-knowledge-cards

一个把长文章浓缩成**知识卡片**的 WorkBuddy Skill：把用户粘贴的文章或本地 Markdown / TXT 文件，转换成 5~8 张精炼的知识卡片，方便快速复习与记忆。

## 1. 项目解决什么问题

阅读长文后「看完就忘」是常见痛点：信息量大、重点分散、难以回顾。这个 Skill 把一篇文章中**真正重要**的知识自动提炼成一张张独立的卡片，每张卡片只讲一个知识点，让复习变成「翻卡片」而不是「重读全文」。它强调**准确提取而非扩写**——卡片只忠于原文，不编造信息。

## 2. 主要功能

- 从文章中提取**真正重要**的知识点（核心概念、关键结论、因果机制、可操作的方法等）。
- 每张卡片固定四部分：**标题、核心知识、简明解释、例子或自测问题**。
- 一张卡片只讲一个知识点，自动删除重复内容。
- 只忠于原文，**不编造原文没有的信息**；原文信息不足时不强行凑数量（默认 5~8 张，信息不足则少于 5 张）。
- 支持「例子」或「自测题」两种结尾：原文有例子就引用，没有就出基于原文的回忆式自测题（附参考答案）。

暂不支持：网页抓取、PDF 解析、Anki 导入、图形界面。

## 3. 安装方法

这是一个纯提示词驱动的 Skill，**无需安装任何脚本或依赖**。只需把整个目录复制到 Skill 目录：

- **用户级**（所有项目可用）：复制到 `~/.workbuddy/skills/make-knowledge-cards/`
- **项目级**（仅当前项目可用）：复制到 `<你的项目>/.workbuddy/skills/make-knowledge-cards/`

```
skills/make-knowledge-cards/
├── SKILL.md            # Skill 定义与提取规则
└── agents/openai.yaml  # 面向 OpenAI Agents 的接口描述
```

## 4. 使用方法

1. 安装后，在对话中**粘贴一段文章**，或**提供一个本地 `.md` / `.txt` 文件路径**。
2. 说「帮我做成知识卡片」「提炼成卡片」等，触发 Skill。
3. Skill 输出若干张 Markdown 格式的知识卡片；若你指定了保存位置，会写入对应的 `.md` 文件，否则直接在对话中输出。

## 5. 输入输出示例

**输入**（粘贴文章，摘要）：

> 生成器是 Python 中一种特殊的迭代器。普通函数一路执行到 return，而生成器通过 yield 可以在执行中途暂停……协程建立在生成器之上，通过 send() 可以向生成器发送值……Python 3.5 之后引入 async/await 语法……

**输出**：

```
本文讲解 Python 生成器与协程的机制与用途。

## 卡片 1：生成器是可暂停的迭代器

**核心知识**：生成器用 yield 在函数执行中途暂停并返回一个值，是一种惰性求值的迭代器。

**解释**：普通函数一路执行到 return，而生成器每次只算下一个值，不一次性生成全部结果，因此处理超大或无限序列时几乎不占内存。

**例子 / 自测**：自测——生成器相比一次性生成完整列表，核心优势是什么？（答：惰性求值，节省内存）

## 卡片 2：创建生成器的两种方式

**核心知识**：生成器表达式或含 yield 的函数都能创建生成器。

**解释**：生成器表达式把列表推导式的方括号换成圆括号，如 (x*x for x in range(10))；含 yield 的函数调用后返回生成器对象，而不是立即执行函数体。

**例子 / 自测**：例子——(x*x for x in range(10)) 就是一个生成器表达式。
```

# Make Knowledge Cards

## 概述

把用户提供的一篇文章（粘贴文本）或本地 Markdown / TXT 文件，提炼成 5~8 张精炼的知识卡片，方便快速复习与记忆。核心价值在于「准确提取」而非「扩写」：卡片只忠于原文，可读且便于自测。

## 何时使用

- 用户粘贴一段文章，要求「做成卡片 / 提炼知识点 / 整理成学习卡片」。
- 用户提供本地 `.md` 或 `.txt` 文件路径，希望浓缩成卡片。
- 用户想要「卡片式」的复习或记忆材料。

不适用于：网页抓取、PDF 解析、Anki 导入、图形界面展示。遇到这些场景直接告知暂不支持，不要自行尝试抓取或解析。

## 输入处理

1. 判断输入类型：
   - 粘贴文本：直接使用。
   - 本地文件路径：仅接受 `.md` / `.txt`；读取文件内容。若文件不存在、扩展名不支持或读取失败，明确告知原因，不要臆造内容。
2. 先通读全文，把握主题、结构、论点与关键术语，再开始提取。不要边读边写。
3. 只使用原文信息，不补充原文没有的事实、数据、结论或背景。

## 提取规则（质量核心）

- **只提取真正重要的知识**：核心概念与定义、关键结论、因果机制、反常识点、可操作的方法步骤、常被忽略的细节。跳过铺垫、客套、重复举例与次要信息。
- **一张卡片只讲一个知识点**：一个知识点若包含多个要点，拆成多张卡片；禁止在一张卡片里堆砌多个主题。
- **删除重复内容**：同一知识点在原文反复出现时，只保留最清晰、信息量最大的一次表述，其余合并。
- **不编造**：卡片中的术语、数字、事实、结论必须来自原文。不得补充原文未提到的例子、背景或扩展结论。
- **不强凑数量**：默认目标 5~8 张；当原文信息不足（如只有 2~3 个真正重要的知识点）时，有多少输出多少，绝不为了凑数添加无关或臆造内容。

## 卡片格式

每张卡片固定四部分：标题、核心知识、简明解释、例子/自测。用以下 Markdown 结构输出：

```
## 卡片 N：<标题>

**核心知识**：<一句话概括结论或定义>

**解释**：<2~3 句，讲清"是什么 / 为什么 / 怎么用">

**例子 / 自测**：<原文已有的例子，或基于原文内容的回忆式自测题>
```

说明：

- 标题用名词短语或短句，直接点出知识点，不要用「卡片 1」这类空标题。
- 「核心知识」突出结论、定义或机制，一句话说清，不展开。
- 「例子 / 自测」二选一：原文有例子就引用原文例子（可精简）；原文无例子就出一道基于原文的自测题（填空 / 判断 / 简答），用于回忆。自测题只能考查原文已讲过的内容，并在题后以「（答：…）」附参考答案，便于自查。
- 卡片之间按「从主干到细节」或原文逻辑顺序排列。

## 输出

- 开头用一句话总览文章主题，再逐张输出卡片。
- 直接以 Markdown 输出，不写多余的开场白或结语。
- 若用户指定了保存位置，把卡片写入对应的 `.md` 文件并告知路径；否则直接在对话中输出。
